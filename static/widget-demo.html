Demo del widget Koala-OS

El widget aparece como una burbuja flotante en la esquina inferior derecha. Hacé click para chatear con el agente.

Cómo embebés esto en tu sitio: 
<script src="https://TU-DOMINIO/static/widget.js" async></script>
Opcionalmente, podés personalizar título, color y saludo: 
<script
  src="https://TU-DOMINIO/static/widget.js"
  data-title="Koala Palermo"
  data-subtitle="Reservas y consultas"
  data-greeting="¡Hola! ¿Querés reservar o consultar el menú?"
  data-color="#2c5530"
  async></script>

API pública del widget

Desde la consola del navegador podés controlar el widget:

  • KoalaWidget.open() — abrir el panel
  • KoalaWidget.close() — cerrar el panel
  • KoalaWidget.reset() — borrar la sesión y empezar de cero
  • KoalaWidget.sessionId() — ver el ID de sesión actual
